# AsilApp
<b>This app is intended for asylum seekers; contains registry functions, health profile, information on reception centers and who to contact in case of need.</b>

The app must alleviate the number of users who contact the healthcare system such as asylum seekers or holders of international protection. It is simulated the existence of a container of essential biomedical equipment (thermometer, sphygmomanometer, blood pressure monitor, scale, glucometer, etc...) which can only be opened by authorized people via the app. The app-container communication for accessing devices is wireless with the insertion of password that only authorized users can have.
