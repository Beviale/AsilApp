# AsilApp
  
<b>This app is natively developed for Android and is written in Java.</b><br><br>
AsilApp is intended for asylum seekers and holders of international protection. Its purpose is to reduce the number of users who contact the healthcare system on a daily basis.
AsilApp contains several features for both the user account and the doctor account.

For the doctor account:<br>
-insertion of new pathologies<br>
-modification of pathologies<br>
-insertion of medicines<br>
-evaluation of a measurement<br>
-recognition via qrcode<br>
-display of user card<br>

For user account:<br>
-management of expenses (medicines, food and more)<br>
-display of pathologies<br>
-display of medicines<br>
-display of blog posts<br>
-display of measurements<br>
-display of information on the reception center<br>
-display of user card<br>



AsilApp communicates with another app (AsilAppBox) that simulates the existence of a container holding essential biomedical equipment such as a thermometer, sphygmomanometer, blood pressure monitor, scale, glucometer, etc. This container can only be opened by authorized individuals and it is useful for taking measurements. Communication between AsilApp and AsilAppBox occurs wirelessly via Bluetooth..
